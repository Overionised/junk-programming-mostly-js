

## Build

The Babylon.js project lives in `cv4`. Build it from that directory:

```sh
cd cv4
npm install
npm run build
```

The build is written to `docs/cv4`, which keeps it separate from the other
projects in this repository. GitHub Pages can publish the `docs` directory
from the `main` branch. The game is then available at:

<https://overionised.github.io/junk-programming-mostly-js/cv4/>
